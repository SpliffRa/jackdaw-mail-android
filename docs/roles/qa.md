# QA-инженер (тестировщик)

## Ответственность
- Тест-план, тест-кейсы, регресс, баг-репорты, верификация на эмуляторе.

## Минимальный тест-план
1. Установка APK на AVD `Pixel_10_Pro_XL`.
2. Навигация по всем разделам Bottom Navigation.
3. Создание тестового письма → список → открытие.
4. SLA: письмо получено в нерабочее время → дедлайн с начала рабочего дня.
5. SLA: переход через выходные → дедлайн в понедельник.
6. Related: цепочка из 3 писем с одним `[Ticket #123]` → группируется.
7. Тёмная/светлая тема, поворот экрана, сворачивание.
8. Offline: выключить сеть → письма из Room доступны, поиск работает.
9. Doze: `adb shell dumpsys deviceidle force-idle` → sync не падает.

## Баг-репорт
- Шаги, ожидаемо/фактически, скрин/видео, `logcat`, версия APK, AVD.
