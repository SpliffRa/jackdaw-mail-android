# Domain-инженер (SLA + Related Emails)

## Ответственность
- `SlaCalculator`: рабочее время по дням недели, дедлайны,
  статусы (OK / Warning / Overdue / Off-hours), переходы через выходные и DST.
- `RelatedEmailFinder`: Message-ID / In-Reply-To / References,
  регэкспы тикетов, фильтр `ORA-*`, нормализация тем.
- Чистые Kotlin-модули без Android-зависимостей.

## Артефакты
- Модули бизнес-логики + юнит-тесты на граничные сценарии.

## DoD
- Покрытие ≥ 90%.
- Тест-кейсы: получение в нерабочее время, переход через выходные, смена часового пояса.
